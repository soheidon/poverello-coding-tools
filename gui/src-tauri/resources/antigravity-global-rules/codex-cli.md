# External Codex CLI rule

## 実体と実行
- 「Codexレビュー」は外部 `codex exec` の実行を指す。内部処理等で代替しない。
- 既定値は `gpt-6-luna`、`model_reasoning_effort=medium`、`approval=never` とする。
- 初回・環境変更後は実体、版、help、認証を確認する（確認済み版 `0.163.0`）。秘密は出さない。
- 読み取り専用レビューは `--sandbox read-only`、計画の直接修正は `--sandbox workspace-write` とする。後者で書けるのは指定された正本計画書1件だけである。
- 失敗時は代替せず報告する。技術的再試行は1回まで。Not Approvedは再試行しない。

## 計画レビュー
1. Codexが計画をレビューし、P0・P1の修正を同じ計画書へ反映する。
2. DeepSeekが同様に確認・修正する。
3. Antigravityが確認・修正して終了判定する。
4. P0・P1または意見相違が残る場合だけ、Codexが最終統合判断を1回行う。

- 通常工程は1周、外部CLIは最大3回とする。
- 最終判断後は計画が変わっても再レビューしない。Approvedなら実装し、Not Approvedなら停止してユーザーへ報告する。
- 同一案件は正本計画書1件を更新し、別版や依頼書を作らない。
- P2や任意改善では修正・再レビューしない。
- 解決済み論点は新証拠・回帰なしに再提起しない。

## 実装レビュー
1. Antigravityが実装・テスト・自己レビューを行う。
2. Codex、DeepSeekが各1回、実装・差分・テスト・同じ計画書の改修欄を確認する。コードは直さない。
3. 不一致時だけCodexが最終判断する。DeepSeekの再承認は不要である。
4. Antigravityが改修・再テストする。最大3周期で止め、残るP0・P1を報告する。

## 判定・境界
- P0=安全等の重大問題、P1=受入不能・重要誤動作、P2=非必須改善とする。
- P0・P1がなくテスト成功なら完了する。全者の同一版Approvedは不要である。
- 1実行20分、計画レビュー全体60分で強制終了し、子プロセスも停止する。
- 計画レビュー中は計画書以外を変更せず、テスト、Git変更、外部接続、deployをしない。
- 証跡は実体・版・設定・日時・対象・前後hash・終了コード・最終回答・変更ファイルとする。推論・秘密・個人情報は残さない。
- Approvedはcommit・release・deploy等の許可ではない。
